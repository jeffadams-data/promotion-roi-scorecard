# Promotion ROI Scorecard
### Measuring True Promotion ROI in Apparel Retail

---

## The Core Finding

A promotion showing **+109% unit lift** can still **surrender $205 in margin**.

This project builds a three-component margin framework that surfaces what unit lift hides — and demonstrates how a revised pricing strategy on the same style flips a $205 loss into a $115 profit.

| Metric | Original Strategy | Revised Strategy |
|---|---|---|
| Discount depth | 25% | 15% |
| Actual units sold | 89 | 82 |
| Cannibalization rate | 29.1% | 5.0% |
| **Net margin impact** | **−$205** | **+$115** |
| **Promo ROI** | **−59.6%** | **+58.9%** |

The revised strategy sold 7 fewer units and generated a $320 improvement in margin outcome. **Volume is not value.**

---

## The Three-Component Framework

```
Net Margin Impact = A + B + C
```

**A — Incremental Margin:** Profit earned on units that genuinely would not have sold without the promotion.

**B — Markdown Cost:** Margin surrendered on units that would have sold at full price anyway — the opportunity cost of the discount.

**C — Cannibalization Loss:** Full-price margin lost on adjacent styles whose demand transferred to the promoted style.
